# 🧮 Modern Calculator

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division

- ⌫ Backspace
- 🧹 Clear button
- 🟢 Error handling
- 🎨 Modern dark UI
- 📱 Responsive layout
- 💻 Desktop support

- Python
